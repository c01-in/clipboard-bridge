# README visual assets

The hero illustration was generated with the built-in image_gen tool. It is concept art, not an app screenshot or evidence of app behavior. The SVG feature cards are deterministic, accessible illustrations authored for this repository.

## Hero generation prompt

Use case: ads-marketing. Asset type: wide GitHub README hero illustration, approximately 2.4:1 landscape. Create a polished editorial 3D product illustration for an open-source Windows and Android clipboard sharing app. A slim desktop PC monitor and keyboard and a clearly Android-style smartphone are the primary subjects, with the same simple text card and a single landscape-photo thumbnail visible across their abstract screens. Show flowing curved two-way transfer paths between the devices, carrying a text card and image card, making clipboard sharing immediately understandable. Minimal premium technology art direction: deep midnight indigo background, soft violet and cyan lighting, frosted glass clipboard cards, tactile matte device frames, restrained glow, generous spacing. Strong readable composition at GitHub README width. Incorporate the exact large English heading 'Clipboard Bridge' and a smaller exact line 'Copy here. Paste there.' in elegant bold modern sans-serif typography. Keep other screen contents abstract, with no small readable text. Do not use fake app screenshots, status metrics, speed claims, brand logos, Apple devices, cloud icons, people, watermarks, account screens or extra decorations. This is a conceptual illustration, not actual app UI.

## Layout references

The page organization draws on [LocalSend](https://github.com/localsend/localsend), [Supabase](https://github.com/supabase/supabase) and [Immich](https://github.com/immich-app/immich): clear product introduction, focused downloads, readable feature sections and navigation. Their artwork and copy were not reused.

The English README remains the default. The Chinese guide uses the same layout with localized feature cards. Google FCM, Google Play Services and Google network requirements must remain visible near the top.
