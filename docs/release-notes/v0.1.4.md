Share text or one image from another Android app by choosing **Clipboard Bridge** in the system Share menu. The entry uses the localized app name, including **剪贴板同步** in Simplified Chinese, and sends to the paired Windows computer without another Send tap. macOS is not supported yet.

On Android 13+, successful receives retain the in-app status and clear the app's progress notification instead of posting an additional copy-success notification. Companion-link copying also uses system feedback on these versions. The separately reported second copy toast in WeChat, with WeChat Keyboard enabled, has **not** been attributed or reproduced on the owner's device; this release does not claim to fix that symptom.

Pairing, pause/resume, authenticated Windows clipboard-write receipts and the 16 MiB content limit remain in effect. New share labels and errors support all nine locales. Debug builds use a separate package and data directory.

Validation: 12 Android API 35 emulator instrumentation tests, including separate-app image URI grants, activity recreation, pause/error paths and notification-enabled feedback checks; 85 Windows protocol/pairing/localization/download checks; signed APK/AAB builds and Android lint. The emulator's protocol peer verifies real encrypted uploads but does not replace a Windows desktop clipboard or Google push delivery test. Long-term delivery and all device vendors remain unverified.

Downloads:
- **ClipboardBridge.apk** — Android installer, signed with the existing release key; preserves pairing when updated in place.
- **ClipboardBridge-Windows-x64-Setup.exe** — Windows installer. Administrator permission required; not Authenticode-signed.
- **ClipboardBridge-Windows-x64.zip** — manual Windows installation.
- **ClipboardBridge.aab** — Google Play upload artifact, not an Android phone installer.
- **ClipboardBridge-Android-Library-Sources.zip** — original UnifiedPush library sources and licenses.
- **SHA256SUMS.txt** — file checksums.

No app account, Firebase project or service-account configuration is needed. Google Play Services and Google network access are still required. GitHub publication is separate from Google Play approval; see [Google Play review notes](https://github.com/c01-in/clipboard-bridge/blob/main/docs/google-play.md).
