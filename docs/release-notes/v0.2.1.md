# 0.2.1 preview — reliable file transfers

This update fixes authenticated Android-to-Windows file requests being rejected when the phone's clock is slightly ahead of the computer. The receiver now allows up to one minute of clock difference at the maximum-lifetime boundary. Expired messages, unpaired requests and excessive future lifetimes remain rejected. Real HTTP regression tests cover the accepted and rejected cases.

All [0.2.0 file-sharing features](v0.2.0.md) remain available: multiple photos, videos and files through Android Share or the system picker, Windows Share and tray sending, transfer progress, cancellation and a configurable receiving folder. Clipboard actions still handle text or one image separately.

Download **ClipboardBridge.apk** for Android. **ClipboardBridge-Windows-Store-Setup.exe** is Microsoft's signed online installer for [Clipboard Bridge in Microsoft Store](https://apps.microsoft.com/detail/9PJT9PTSMCJQ); it downloads the currently published Store version, so Store certification can delay the Windows update. It requires Internet access and Store components, with no Developer Mode or certificate import. The AAB is for maintainer uploads, not phone installation.

Google Play submission and Microsoft Store certification are separate from GitHub publication. A published GitHub release does not mean either store has approved its update. Use matching current endpoints for file transfers; devices still need a reachable network connection and Android needs Google Play services and access to Google's network for push.
